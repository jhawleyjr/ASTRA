# Reviews

Store independent findings and human decisions here when a brief/PR body is insufficient.
Start from the [review-findings template](../templates/review-findings.md) and follow the
[risk-based workflow](../process/workflow.md). Link architecture, ADRs, and related artifacts rather
than copying them. Small tasks need no extra file. Templates are optional forms, not an extra gate.

What Joe reviews goes in the PR body, from the [PR description template](../templates/pr-description.md). These are evidence
records: record exact reviewed revisions here, while keeping transient pins out of standing rules; task handoffs may cite this evidence.
