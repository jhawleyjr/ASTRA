# Tasks

Store bounded ownership and dependency handoffs here when a brief/PR body is insufficient.
Start from the [work-package template](../templates/work-package.md) and follow the
[risk-based workflow](../process/workflow.md). Link architecture, ADRs, and related artifacts rather
than copying them. Small tasks need no extra file. Templates are optional forms, not an extra gate.

For multiple packages use `<feature>/STATUS.md` from the [manifest template](../templates/task-status.md).
Keep PLAN as the milestone checklist and STATE as the session handoff.
